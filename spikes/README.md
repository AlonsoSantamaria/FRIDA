# Non-binding engineering spikes

Everything under this directory is disposable and does **not** establish an architecture baseline.

Permitted while preparation is GREEN:

- local ADK import and structured-output probes;
- state-machine experiments that do not implement FRIDA's canonical flow;
- adapter and persistence feasibility checks;
- deterministic reliability, restart, and idempotency experiments.

Every spike must state its question, assumptions, result, and deletion criteria. Do not use a spike to freeze agent composition, select a paid service, claim an external capability, or bypass Gate A clearance.
